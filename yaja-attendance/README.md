# 야자 출석체크 앱

고2 8교시·야자 출석을 관리하는 구글 시트 + Apps Script 웹앱입니다.

| 파일 | 내용 |
|---|---|
| `Code.gs` | 서버 코드 (시트 읽기·쓰기, 출석 계산) |
| `Index.html` | 화면 (학생 3개, 교사 2개 탭) |
| `appsscript.json` | 설정 (서울 시간대, 학교 도메인 사용자만 접속) |
| `DESIGN.md` | 디자인 가이드 |

## 배포 방법 (관리자 1회, 약 10분)

학교 구글 계정(Workspace)으로 진행합니다.

1. **스프레드시트 만들기**
   구글 드라이브에서 새 스프레드시트를 만듭니다. 이름 예: `야자 출석`
2. **스크립트 붙여넣기**
   - 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
   - 기본 파일 `Code.gs`의 내용을 지우고 이 폴더의 `Code.gs`를 붙여넣습니다.
   - 왼쪽 **파일 +** → **HTML** → 이름을 `Index`로 하고 `Index.html` 내용을 붙여넣습니다.
   - **프로젝트 설정(톱니바퀴)** → "편집기에서 appsscript.json 매니페스트 파일 표시"를 켜고, `appsscript.json`을 이 폴더의 내용으로 바꿉니다.
   - 저장합니다.
3. **시트 만들기**
   편집기 위쪽 함수 목록에서 `setup`을 고르고 **실행**합니다. 처음 실행할 때 권한 승인 창이 뜨면 허용합니다.
   스프레드시트에 `학생`, `교사`, `정기신청`, `예외입력`, `감독배정`, `출석기록`, `운영안함` 시트가 생깁니다.
   script.google.com에서 바로 만든 독립 프로젝트라면 드라이브에 `야자 출석 데이터` 스프레드시트가 새로 만들어집니다. 주소는 **실행 로그**에 나옵니다.
4. **명단 입력**
   - `학생` 시트: 이메일, 학번, 반, 번호, 이름
   - `교사` 시트: 이메일, 이름, 역할(`교사` 또는 `관리자`), 담당반(숫자만, 예: `3`)
   - `감독배정` 시트: 날짜(`2026-10-14` 형식), 감독 교사 이메일 — 하루 1명
   - `운영안함` 시트: 야자가 없는 날(시험, 휴업일)
5. **배포**
   - 편집기 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**, 액세스 권한: **(학교 도메인) 내 모든 사용자**
   - **배포**를 누르고 나온 **웹 앱 URL**을 학생·교사에게 공유합니다.
6. **증빙 사진 폴더 공유**
   학생이 처음 사진을 첨부하면 관리자 드라이브에 `야자 출석 증빙` 폴더가 생깁니다. 담임 선생님이 사진을 볼 수 있도록 이 폴더를 교사들과 공유하세요.

코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다. URL은 그대로입니다.

## 동작 규칙

- **출석 명단** = 그 요일·교시 신청자 − 결석 − 조퇴(조퇴 시각 이후 끝나는 교시) − 교시별 사유 입력자
- 결석·조퇴·사유는 **교시 시작 전에 입력한 것만** 반영됩니다. 시작 후에는 관리자가 시트에서 직접 고칩니다.
- 학생은 그날 8교시(16:40) 시작 전까지 자기 입력을 삭제할 수 있습니다.
- 출석 체크는 **그날 감독 교사와 관리자만** 할 수 있습니다. 다른 교사는 조회만 됩니다.
- 이름을 누르면 출석 → 지각 → 미출석 순서로 바뀝니다.
- 감독 교사가 체크한 교시가 끝났는데 체크되지 않은 학생은 **무단 불참**으로 계산합니다. 아무도 체크하지 않은 교시는 통계에서 뺍니다.
- 담임은 담당반만, 관리자는 모든 반을 조회합니다. 학기는 3월 1일 / 8월 1일부터로 계산합니다.

## 알려진 제한

- 정기 신청은 현재 신청 내용만 저장합니다. 신청을 바꾸면 지난 주 통계도 바뀐 신청 기준으로 다시 계산됩니다.
- Apps Script는 동시 실행 수에 한도가 있습니다. 출석 체크가 몰리는 시간에 느려지는지 시험 운영으로 확인하세요.
- 화면의 "오늘" 날짜와 기본 교시는 사용하는 기기의 시계를 따릅니다. 입력 마감 판단은 서버(서울 시간)가 합니다.
