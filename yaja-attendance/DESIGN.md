# 야자 출석체크 앱 디자인 가이드

Figma 화면 설계: https://www.figma.com/design/TyQe44mANVVQJpRc9wkEA3

## 1. 디자인 방향

| 원칙 | 내용 |
|---|---|
| 빠르게 | 감독 교사가 한 손으로 1~2초 안에 출석을 체크할 수 있게 한다. 터치 영역은 최소 44px. |
| 한눈에 | 출석 상태는 글자와 색을 함께 쓴다. 색만으로 구분하지 않는다. |
| 차분하게 | 밤 시간대에 쓰는 앱이다. 밝은 화면(기본)과 어두운 화면(야간)을 모두 지원한다. |
| 모바일 우선 | 기준 폭 390px. PC에서는 가운데 정렬하고 최대 폭 480px. |

## 2. 색상

| 토큰 | 값 | 용도 |

| `primary` | `#2563EB` | 주요 버튼, 선택된 칩, 활성 탭 |
| `primary-soft` | `#DBEAFE` | "예정" 상태 배경 |

| `text-sub` | `#6B7280` | 보조 설명, 반 표시 |
| `text-hint` | `#9CA3AF` | 입력칸 안내 문구 |
| `line` | `#E5E7EB` | 구분선, 탭바 테두리 |
| `border` | `#D1D5DB` | 입력칸, 선택되지 않은 칩 |

### 야간(다크) 모드

야자 시간대(18:40 이후)에 휴대폰 설정이 다크 모드이면 자동으로 적용한다.

| 토큰 | 값 |
|---|---|
| `bg` | `#0B1220` |
| `surface` | `#151E2E` |
| `text` | `#E5E7EB` |
| `text-sub` | `#9CA3AF` |
| `line` | `#243045` |
| `primary` | `#3B82F6` |

다크 모드의 상태 색은 글자를 한 단계 밝게(`#4ADE80`, `#FBBF24`, `#F87171`), 배경은 해당 색의 15% 투명도로 쓴다.

## 4. 간격과 모양

| 항목 | 값 |
|---|---|
| 간격 단위 | 4px 배수 (4, 8, 12, 16, 20, 24) |
| 화면 좌우 여백 | 16px |
| 카드 사이 간격 | 16px |
| 카드 안 여백 | 14~16px |
| 카드 모서리 | 16px |
| 버튼·입력칸 모서리 | 12px / 10px |

## 5. 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| **버튼** | 주요: `primary` 배경 + 흰 글자. 보조: 흰 배경 + `primary` 테두리·글자. 높이 52px, 가로 꽉 채움. |
| **칩** | 선택: `primary` 배경 + 흰 글자 Bold. 미선택: 흰 배경 + `border` 테두리. 여러 개면 줄바꿈. |
| **세그먼트** | 회색 바탕 안에 선택 항목만 흰 칸. 종류(결석/조퇴/사유)와 교시 선택에 사용. |
| **상태 배지** | 알약형, 12px. 상태 색 표를 따른다. |
| **신청 표 체크칸** | 32×32px, 모서리 8px. 선택 시 `primary` 배경 + 흰 체크 표시. |
| **출석 행** | 높이 48px 이상. 반 · 이름 · 상태 배지 순. 행 전체를 누르면 출석 → 지각 → 미출석 순서로 바뀐다. |
| **통계 카드** | 3개를 가로로 나란히. 라벨(12) 위, 숫자(22 Bold) 아래. |
| **탭바** | 하단 고정. 활성 탭은 `primary` 글자 + 위쪽 점. 학생 3개, 교사 2개. |

## 6. 화면 목록

| 번호 | 화면 | 사용자 |
|---|---|---|
| ① | 정기 신청 (요일 × 교시 표) | 학생 |
| ② | 불참 입력 (결석 / 조퇴 / 교시별 사유) | 학생 |
| ③ | 내 현황 (이번 주 일정, 출석률) | 학생 |
| ④ | 출석 체크 (지금 교시 명단) | 감독 교사 |
| ⑤ | 우리 반 조회 | 담임 |

## 7. 문구 규칙

- 버튼·라벨은 짧은 명사형으로 쓴다. 예: "제출", "저장", "불참 예정 8명"
- 안내 문장은 "~합니다"체로 쓴다. 예: "입력하면 바로 출석 명단에서 빠집니다"
- 시간은 `18:40~20:00`, 날짜는 `10/14(수)` 형식으로 쓴다.
- 교시 이름은 `8교시`, `야자 1교시`, `야자 2교시`로 통일한다. 좁은 곳에서만 `야자1`, `야자2`로 줄인다.
- 안내 문구는 `※`로 시작하고 `text-sub` 색, 12px로 쓴다.

## 8. 접근성

- 본문 글자와 배경의 명암비는 4.5:1 이상을 지킨다.
- 상태는 항상 글자(출석/지각/미체크)를 함께 표시한다.
- 터치 영역은 44×44px 이상으로 한다.
