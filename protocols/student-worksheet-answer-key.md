# [교사용] 학생 활동지 예시 답안

> 학생용 활동지와 함께 사용 · 실험 근거와 참고 문헌: 실험 프로토콜 문서(asymmetric-synthesis-camp.md)

## 0. 생각 열기
- **Q0-1** 거울상이지만 어떻게 돌려도 서로 겹쳐지지 않는다(카이랄).
- **Q0-3** 옳지 않다. 탈리도마이드는 체내에서 라세미화된다(혈청 중 반감기 약 1 h; Mori et al., *Sci. Rep.* 2018). 따라서 한쪽만 투여해도 양쪽이 생긴다. 카이랄성 분석은 필요하지만 그것만으로 충분하지 않다는 점을 짚는다.

## 활동 1
- **Q1-1** A, B 중 스피어민트 향 = **(R)-(−)-카르본**, 캐러웨이 향 = **(S)-(+)-카르본**
- **Q1-2** 후각 수용체는 카이랄 단백질이라 거울상 분자와 맞물리는 방식(결합)이 달라 서로 다른 신호를 낸다.
- **1-2** 고리의 이소프로페닐기가 붙은 탄소(C5)가 카이랄 중심. 작용기: 케톤(C=O), 알켄(C=C)
- ※ 리모넨(오렌지/레몬) 예시는 사실이 아니므로 사용하지 않는다(Kvittingen et al., *J. Chem. Educ.* 2021).

## 활동 2
- 회전 / 우선성(+) / 좌선성(−) / l = **1 dm**
- 수크로스 예상 α: 5.0 g/100 mL → +3.3°, 10.0 → +6.65°, 15.0 → +10.0°
- **Q2-1** 원점을 지나는 직선. 기울기 = [α] × l
- **Q2-2** 빛이 산란·굴절되어 투과광과 경로가 흐트러지므로 측정값이 불안정하거나 틀려진다.

## 활동 3
- **Q3-1** 반응물: 케톤 + 에스터 / 생성물: 하이드록시기(알코올) + 에스터 / 케톤 → 2차 알코올
- **Q3-2** 생성물. 3번 탄소에 붙은 –H, –OH, –CH₃, –CH₂COOC₂H₅
- **Q3-3** 반응 전: C 0, C 0, O(이중) +2 → **+2** / 반응 후: C 0, C 0, H −1, O +1 → **0** → 감소 → **환원**
- **Q3-4** R₂C=O + **2**H⁺ + **2**e⁻ → **R₂CH–OH**
- **Q3-5** 효모가 설탕을 산화(발효)하며 얻은 전자를 NADPH 형태로 저장하고, 효소가 이를 써서 케톤을 환원한다. 설탕 산화와 케톤 환원이 짝지어 일어난다.
- **Q3-6** H가 붙는 면에 따라 (R)/(S)가 결정된다. 효소의 활성 자리는 카이랄이라 기질이 한 방향으로만 들어맞아 한쪽 면을 우선 선택한다.
- 체크리스트: 효모 세포 제거 / 염석 → 유기물의 수층 용해도 감소, 유화 감소 / 에틸 아세테이트(밀도 0.90)는 물보다 가벼워 **위층** / 밀봉 금지 → 발효 CO₂ 압력

## 활동 5 (채점 포인트)
- **Q5-1** 비카이랄 반응물에서 광학 활성 생성물이 생겼다 → 한쪽 거울상이 더 많이 생겼다(비대칭 합성).
- **Q5-2** "회전은 효모나 남은 설탕(수크로스 +66.5°)에서 왔다"는 반론. 블랭크 ≈ 0°면 결론을 지지한다.
- **Q5-3** 효모에는 (R)·(S)를 만드는 여러 환원효소가 공존, 증류 생략으로 불순물 포함, 용매 차이, 농도·무게 측정 오차 등
- **Q5-4** 미반응, 추출 불완전, 유화로 인한 손실, 효모 찌꺼기 흡착, 농축 중 휘발
- **Q5-5** 비선광도는 용매에 따라 달라 ee가 근사값이다 → 문헌과 같은 조건으로 재측정, 또는 표준 시료로 에탄올에서 [α]max를 직접 측정
- **Q5-6** 촉매를 완벽히 순수하게 만들지 않아도 높은 광학 순도의 의약품을 얻을 수 있어 비용·공정이 효율적이다. 생명체의 단일 카이랄성 기원 설명에도 연결된다.
