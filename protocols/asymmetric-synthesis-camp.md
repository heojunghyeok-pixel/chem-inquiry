## 1. 실험 개요

**반응:** 에틸 아세토아세테이트(케톤) → 빵 효모(산화환원효소, NADPH) → **(S)-(+)-에틸 3-하이드록시부타노에이트**

```
CH3–C(=O)–CH2–COOC2H5   ──(빵 효모, 설탕, 물, 실온)──▶   CH3–C*H(OH)–CH2–COOC2H5
 에틸 아세토아세테이트 (비카이랄)                       (S)-에틸 3-하이드록시부타노에이트 (카이랄, 우선성 +)
```

- 반응물은 **비카이랄**(광학 비활성), 생성물은 **카이랄**(광학 활성) → 편광계로 "비대칭 합성이 일어났는가"를 직접 판정할 수 있음.
- 원 논문: Seebach et al., *Org. Synth.* **1985**, 63, 1; *Coll. Vol.* 7, 215 [R1]
- 교육용 선례: Pohl, Clague, Schwarz, *J. Chem. Educ.* **2002**, 79, 727 (NaBH₄ 라세미 환원 vs 효모 비대칭 환원 비교) [R2]

## 3. 편광계 측정 프로토콜

### 3-1. 장비 사양 (PS-3237 Quick Start Guide 012-16881A 기준 [R9])
- 광원 589 nm(나트륨 D선과 동일) · 시료 셀 경로 길이 **100 mm (= 1 dm)** · 엔코더 분해능 0.09°
- 최신판 매뉴얼(012-16881B)에서 사양 변동 여부 확인 권장

### 3-2. 시료 준비 및 예상값
1. 농축한 생성물 전량(약 2.5 g)을 에탄올에 녹여 **25.0 mL 부피플라스크**로 정용 → c ≈ 0.10 g/mL
2. 주사기로 셀에 기포 없이 채움
3. 예상 회전각 (Biot 법칙 α = [α]·l·c):

```
α ≈ (+37°) × (1 dm) × (0.10 g/mL) ≈ +3.7°   → 분해능 0.09°보다 충분히 큼
```

> ⚠️ 문헌 [α]값은 **클로로폼(CHCl₃)** 용매 기준. 에탄올 용액의 비선광도는 다를 수 있으므로 아래 ee 계산은 **근사값**임을 보고서에 명시.

### 3-3. 대조 실험 (필수 — 탐구의 핵심)

| 시료 | 예상 결과 | 확인하는 것 |
|---|---|---|
| ⓐ 수크로스 수용액 10.0 g/100 mL | α ≈ +6.65° ([α]D = +66.5°) | 장비 보정·조작 연습 |
| ⓑ 반응물(에틸 아세토아세테이트) 에탄올 용액 | α ≈ 0° | 반응물은 광학 비활성 |
| ⓒ **블랭크**: 효모 + 설탕만(반응물 없이) 동일 후처리 | α ≈ 0° 이어야 함 | 측정된 회전이 **효모 유래 카이랄 불순물(잔류 당 등)이 아님**을 입증 |
| ⓓ 생성물 | α > 0 (우선성) | 비대칭 합성 성공 |
| ⓔ (R)-카르본 / (S)-카르본 (도입 활동 시료) | 부호 반대 | 거울상 이성질체 = 회전 방향 반대 |

> ⓒ가 0이 아니면 ⓓ에서 ⓒ를 빼서 보정하고, 그 한계를 고찰에 기술.

### 3-4. 보고서 계산식

```
수율(%)         = 실제 수득량(g) / 4.06 g × 100
비선광도 [α]    = α_obs / (l[dm] × c[g/mL])
광학 순도(ee,%) ≈ [α]_obs / [α]_max × 100     ([α]_max = +43.5°, CHCl3, c 1.0 [R1])
거울상 비율      (S) = (100 + ee)/2 %,  (R) = (100 − ee)/2 %
```
예) ee 85% → (S) 92.5% : (R) 7.5%

## 5. 「화학 반응의 세계」(2022 개정) 연계 포인트

> 성취기준 문구는 나무위키 정리본에서 확인한 것이므로 교육부 고시 제2022-33호 [별책 9] 원문과 대조 권장 [R10].

| 성취기준 | 실험 속 연계 내용 |
|---|---|
| **[12반응02-01]** 전자의 이동과 산화수 변화로 산화⋅환원 반응을 이해하고, 반쪽 반응식을 활용하여 산화⋅환원 반응식을 완성할 수 있다. | • 카보닐 탄소 산화수 **+2 → 0** (환원)<br>  – 케톤 C: C–C(0), C–C(0), C=O(+2) → **+2**<br>  – 알코올 C: C–H(−1), C–O(+1), C–C(0)×2 → **0**<br>• 반쪽 반응식: R₂C=O + 2H⁺ + 2e⁻ → R₂CH–OH<br>• 환원제는 효모 속 NADPH, 그 전자는 설탕 산화(발효)에서 공급 → **짝지어진 산화·환원** |
| **[12반응03-01]** 일상생활에 유용한 탄소 화합물을 작용기에 따라 분류할 수 있다. | 반응물: 케톤 + 에스터 / 생성물: 하이드록시기 + 에스터 / 카르본: 케톤 + 알켄 |
| **[12반응03-02]** 간단한 탄소 화합물의 화학 반응 예를 찾아 작용기의 변화로 설명할 수 있다. | 케톤(C=O) → 2차 알코올(CH–OH). 평면 카보닐의 **어느 면**에 H가 붙느냐가 (R)/(S)를 결정 → 효소가 한 면을 선택 |
| **[12반응03-04]** 탄소 화합물의 반응을 통해 합성된 새로운 물질이 과학⋅기술⋅사회 발전에 끼친 영향을 조사하여 화학의 유용성을 깨달을 수 있다. | 탈리도마이드, 카이랄 의약품, 노벨화학상 2001(비대칭 촉매)·2021(유기촉매)·2026(비선형 효과·자기촉매) |
| **[12반응01-01]** 브뢴스테드-라우리 산과 염기의 정의를 이해하고, 이에 따라 산과 염기를 구별할 수 있다. | (심화 실험 B) 프롤린의 양쪽성 이온: –COOH(양성자 주개)·–NH(양성자 받개)가 촉매 작용에 함께 관여 |

- 교과 간 연계(참고): 반응 속도·촉매는 2022 개정에서 「물질과 에너지」, 효소는 「세포와 물질대사」에 배치됨 [R10].

## 6. (선택) 심화 실험 B — L-프롤린 유기촉매 비대칭 알돌 반응

2021 노벨화학상(List·MacMillan) 연계. 원 논문 조건 [R4]:
4-나이트로벤즈알데하이드 + 아세톤, **L-프롤린 30 mol%**, DMSO/아세톤 = 4 : 1, 실온 4 h → 수율 68%, **76% ee**.
Kagan의 1986년 비선형 효과 첫 보고에도 프롤린 촉매 반응(Hajos–Parrish)이 포함됨 [R7].

| 시약 | 1 mmol 규모 예시 (계산값) |
|---|---|
| 4-나이트로벤즈알데하이드 (M 151.12) | 151 mg (1.0 mmol) |
| L-프롤린 (M 115.13) | 35 mg (0.30 mmol, 30 mol%) |
| DMSO | 4.0 mL |
| 아세톤 | 1.0 mL |

> 한계(사전 인지 필요): ① 원 논문의 기질 농도는 직접 확인하지 못해 위 표는 비율 기준 계산값 ② 생성물 약 0.1 g 수준 → 편광계 회전각이 작아 판정이 어려울 수 있음 ③ DMSO 제거·정제(TLC/컬럼) 필요, ee 정량은 보통 카이랄 HPLC 사용 → **교사 예비실험 후 채택 여부 결정 권장.** 4-나이트로벤즈알데하이드는 자극성 물질.

## 7. 안전

- 에틸 아세토아세테이트·에틸 아세테이트: 자극성, 인화성 → 흄후드, **화기 금지**, 보안경·장갑
- 분액깔때기: 흔든 뒤 반드시 마개 쪽을 위로 해 가스 배출
- 발효 플라스크는 밀봉 금지(CO₂ 압력)
- 시향은 바람 일으키기 방식만, 시음 금지
- 폐액: 유기 폐액 / 수용액 폐액 분리 수거, 효모 찌꺼기는 일반 폐기 전 학교 지침 확인

| **① 반응 시간과 광학 순도** | 반응 24/48/72 h | [α]·ee 변화 (원문 교육 자료: 발효가 길수록 ee 증가 경향 [R3]) |
| **② 효모 종류 비교** | 건조 이스트 / 생효모 / 막걸리·맥주 효모 | 수율, [α] |
| **③ 설탕(에너지원) 양과 수율** | 수크로스 0 / 15 / 30 / 45 g | 수율, 미반응물 비율 → 산화·환원 짝반응 관점 해석 |
| **④ 비대칭 vs 대칭 합성 비교** | 효모 환원 vs NaBH₄ 환원(교사 시연, [R2] 조건 참고) | NaBH₄ 생성물은 라세미 → α ≈ 0 예상 |
| **⑤ 비선형 효과 모의실험 (2026 노벨상 직결)** | 엑셀/파이썬으로 촉매 ee와 생성물 ee 관계 모델링 | 선형(ee_prod = ee_cat × ee_max) vs Kagan 비선형 곡선 비교 |
| **⑥ 분자 모델링/AI** | (R)/(S)-탈리도마이드를 세레블론(CRBN) 구조(PDB 5YIZ 등)에 도킹 | 문헌상 (S)체가 CRBN에 약 10배 강하게 결합 [R8] → 시뮬레이션 결과를 이 실험값과 비교·검증 |

> ⑥ 주의: 도킹 점수는 근사 계산이므로 **실험 문헌값과 대조**하는 방식으로 설계하고, 체내 라세미화 사실 [R8]을 함께 고찰하게 할 것.
