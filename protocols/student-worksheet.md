### 4-2. 계산

| 항목 | 식 | 계산 과정 | 결과 |
|---|---|---|---|
| 이론 수득량 | 4.0 g ÷ 130.14 g/mol × 132.16 g/mol | | ______ g |
| 수율 | 실제 수득량 ÷ 이론 수득량 × 100 | | ______ % |
| 농도 c | 생성물 질량(g) ÷ 25.0 mL | | ______ g/mL |
| 보정 회전각 | α(ⓓ) − α(ⓒ) | | ______ ° |
| 비선광도 [α] | 보정 α ÷ (l × c) | | ______ ° |
| 광학 순도 ee | [α] ÷ 43.5 × 100 | | ______ % |
| (S)형 비율 | (100 + ee) ÷ 2 | | ______ % |
| (R)형 비율 | (100 − ee) ÷ 2 | | ______ % |

> ※ 문헌값 +43.5°는 순수한 (S)형을 클로로폼에 녹여 잰 값이다. 우리는 에탄올을 썼으므로 ee는 **근사값**이다.
